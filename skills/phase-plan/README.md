# Phase-plan skill

This folder contains the `phase-plan` skill copied from the upstream project:

- **Upstream repository:** https://github.com/BCYAYAY14/phase-plan
- **Original skill file:** https://github.com/BCYAYAY14/phase-plan/blob/main/skills/phase-plan/SKILL.md

The skill helps break remaining repository work into ordered phases, recommend a model tier and effort level for each phase, agree the plan with the user, and track progress.

**Compatibility note:** The original skill is designed primarily for Claude Code. It refers to Claude Code tools, model names, subagents, and repository workflows. Adding it here does not automatically make those tools available in ChatGPT or another assistant. Adapt the host-specific instructions before treating it as native to another platform.

The `de-ai-writing` skill at the repository root remains a separate writing-editing workflow. This skill does not replace or change it.
